# esp32-hardware-cookbook

A personal reference and growing collection of ESP32 hardware examples.
wiring notes and working code for the sensors, displays and actuators I use.
Mostly kept so future-me doesn't have to re-learn the same component twice.

## What's inside

- **sensors** — environment and input sensors
- **displays** — screens and panels
- **actuators** — things that beep, move or switch

Each category has one folder per component and each component folder holds
working examples with the wiring and pin details in the code comments.

## How to use it

Open the folder for the component you're working with, check the comments for
wiring and pins, and copy what you need into your own project.

## Notes

- Built for the ESP32 using the Arduino framework.
- New components get added over time, so expect the folders to keep growing.
